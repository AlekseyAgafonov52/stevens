# Как запустить Stevens (копия для просмотра)

Это копия репозитория AlekseyAgafonov52/stevens: бэкенд из `main` и фронт из ветки `frontend` в одной папке.
Оригинал не изменён. В копии только правки, без которых проект не запускается (список внизу).

## На компьютере (Windows, macOS, Linux)

Нужен только **Docker Desktop**: https://www.docker.com/products/docker-desktop/ (установить и запустить).

1. Распакуйте архив и откройте терминал в папке `stevens`.
2. (Необязательно) Ключи YandexGPT: скопируйте `.env.example` в `.env` и впишите `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`.
   Без ключей всё запустится, вход и регистрация работают, но на любое сообщение чат ответит «Не уловил».
3. Запустите:
   ```
   docker compose up --build
   ```
   Первый раз сборка занимает 3–5 минут.
4. Откройте http://localhost:8080 , нажмите «Регистрация» (имя, email, пароль от 6 символов) и пишите в чат.
   Документация API (Swagger): http://localhost:8000/docs

Остановить: `Ctrl+C`, потом `docker compose down`. Стереть базу: `docker compose down -v`.

## Через GitHub (без установки, в браузере)

1. Залейте эту папку в свой репозиторий на GitHub (в архиве уже есть git-история):
   ```
   git remote add origin https://github.com/<вы>/stevens-copy.git
   git push -u origin local-run
   ```
2. На странице репозитория: **Code → Codespaces → Create codespace on local-run**.
3. Codespace сам соберёт и запустит проект (3–5 минут) и откроет порт **8080** в браузере.
   Если вкладка не открылась: **Ports** → 8080 → значок глобуса. Перезапуск вручную: `docker compose up --build -d`.
   Ключи Yandex можно задать как секреты Codespaces с теми же именами или файлом `.env`.

## Только интерфейс, без бэка

Фронт умеет показывать заготовленные ответы по контракту (подтверждения, конфликты и т. п.), без базы и LLM.
Нужен Node.js 22+:
```
cd frontend
npm install --global pnpm@11.25.0
pnpm install
pnpm dev:mock
```
Откройте http://127.0.0.1:5173 и нажмите «Попробовать без регистрации».

## Что изменено в копии по сравнению с оригиналом

- `requirements.txt`: добавлены недостающие пакеты (`openai`, `dateparser`, `passlib`, `bcrypt`, `email-validator`, `greenlet`).
- `brain.py`: без ключей Yandex сервер не падает при старте, а пишет предупреждение.
- `Dockerfile` (новый) для бэка и общий `docker-compose.yml`: база, бэк и фронт одной командой.
- `frontend/nginx.conf` и `frontend/Dockerfile`: фронт проксирует `/api` на бэк, поэтому всё открывается с одного адреса (и в Codespaces тоже).
- `.env.example` в корне и этот файл.

Логику бэка и фронта не трогал.
