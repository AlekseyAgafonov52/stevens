# 02. Экраны и состояния

Макетов нет — этот документ их заменяет. Всё, что видно, описано здесь; размеры и цвета — токенами из `04-style.md` / `tokens.css`. Тексты — ключами из `src/content/texts.ts` (в описании — сам текст, в коде — ключ).

Экранов два: **вход** и **приложение**. Плюс два окна подтверждения и меню в шапке.

## 1. Экран входа

Показывается, если включён флаг `auth`, нет действующего токена и человек не выбрал песочницу раньше (см. `03-behavior.md`, раздел «Режимы»). Шапки нет.

**Раскладка.** Фон `--c-bg`. Колонка шириной 400 (на телефоне — экран минус 2×16), по центру по горизонтали; по вертикали — центр, но не ближе 48 к верху. Сверху вниз:

1. «Stevens» — Plex Serif 500, 32 px, `--c-text`, по центру.
2. Подзаголовок `start_subtitle` — 15, `--c-text-2`, по центру, отступ сверху 8.
3. Карточка формы, отступ сверху 28: фон `--c-surface`, рамка 1 px `--c-line`, скругление 16, отступ 24.
4. Разделитель `auth_or`, отступ сверху 20: линия 1 px `--c-line` — слово 12 `--c-text-2` — линия; слово с отступами по 12.
5. Кнопка `auth_sandbox_button`, отступ сверху 20, на всю ширину колонки.
6. Пояснение `auth_sandbox_hint` — 13, `--c-text-2`, по центру, межстрочный 1,45, отступ сверху 10.

Если сервер просыпается — под пояснением строка статуса `status_waking` (13, `--c-text-2`, по центру); не проснулся за 60 с — `status_server_down` терракотой со значком.

Если человек попал сюда из-за протухшего токена — над карточкой формы плашка `auth_session_expired`: 13, `--c-text-2`, по центру, без фона.

**Карточка формы.**
- Вкладки `auth_tab_login` | `auth_tab_register`: две кнопки-текста в ряд, каждая на половину ширины, высота 40, 15/500. Активная — `--c-text` и линия 2 px `--c-text` снизу; неактивная — `--c-text-2`, линия 1 px `--c-line`. По умолчанию «Вход». Переключение очищает ошибки, но не поля.
- Поле «Логин», отступ сверху 20; поле «Пароль», отступ сверху 14. Подпись над полем — 13, `--c-text-2`, отступ снизу 6. Поле: высота 44, отступ слева 12, скругление `--r-button`, рамка 1 px `--c-line`, фон `--c-bg`, текст 15 (на телефоне 16). Фокус — рамка `--c-text-2` + обводка фокуса.
- У пароля справа внутри поля кнопка-глаз 32×32 (`Eye` / `EyeOff`, 18, `--c-text-2`), `aria-label` = `auth_show_password` / `auth_hide_password`.
- Ошибка поля — под полем, 13, `--c-alarm`, отступ сверху 6; рамка поля — `--c-alarm-line`.
- Общая ошибка (`auth_err_credentials`, сеть) — над кнопкой, 13, `--c-alarm`, со значком `CircleAlert` 14.
- Кнопка отправки, отступ сверху 20: на всю ширину, высота 44, скругление `--r-button`, фон `--c-text`, текст `--c-on-dark` 15/500. Текст — `auth_submit_login` или `auth_submit_register`. Во время запроса — неактивна, вместо текста три точки индикатора.
- Только на вкладке «Регистрация»: под кнопкой `auth_register_hint` — 13, `--c-text-2`, по центру, отступ сверху 10.

**Кнопка песочницы.** Высота 44, скругление `--r-button`, рамка 1 px `--c-ghost`, фон прозрачный, текст `--c-text` 15/500. Наведение — фон `--c-bubble`.

Enter в любом поле — отправить форму. Автофокус на «Логин» на компьютере; на телефоне без автофокуса (иначе сразу выскакивает клавиатура).

## 2. Приложение: каркас

Высота `100dvh`. Три слоя сверху вниз: **шапка** (закреплена) → **лента** (прокручивается только она) → **низ**: строка статуса и строка ввода (закреплены). Контент ленты и низа — в колонке `--column` (720) по центру.

### 2.1 Шапка

Высота `--header-h`, фон `--c-header`, снизу рамка 1 px `--c-line`, по бокам `--gutter`. Сетка из трёх колонок `1fr auto 1fr`.

- **Слева — «Новый диалог».** Кнопка: высота 36, отступы 0 12, скругление `--r-button`, рамка `--c-line`, фон `--c-surface`, иконка `Plus` 16 + текст 14/500, зазор 8. Скрыта на пустой ленте. Неактивна (прозрачность 0,4, без нажатия) во время записи голоса и ожидания ответа. На телефоне — только иконка 36×36, `aria-label` = `btn_new_dialog`.
- **По центру — «Stevens».** Plex Serif 500, `--fs-name`, `--c-text`. Не кликается.
- **Справа — режим.** Только при включённом флаге `auth`; при выключенном — пусто, кроме метки песочницы (см. ниже).
  - В песочнице: метка-кнопка `header_sandbox` — высота 30, отступы 0 10 0 12, скругление `--r-pill`, рамка 1 px `--c-line`, фон прозрачный, текст 13 `--c-text-2` + `ChevronDown` 14, зазор 4. Открывает меню: `menu_reset_sandbox`, `menu_go_auth`. При выключенном `auth` в меню только `menu_reset_sandbox`.
  - В аккаунте: кружок 34, фон `--c-text`, первая буква логина заглавной, `--c-on-dark` 13/600, `aria-label` = `profile_label`. Открывает меню: первая строка — логин (13, `--c-text-2`, не кликается, разделитель снизу), затем `menu_logout`.

**Меню.** Выпадает под кнопкой, выровнено по правому краю. Фон `--c-surface`, рамка `--c-line`, скругление 12, тень `--shadow-float`, отступ 6, минимальная ширина 220. Пункт: высота 36, отступ 0 12, скругление 8, текст 14 `--c-text`, наведение и фокус — фон `--c-bubble`. Закрывается: выбор пункта, клик вне, Escape. Стрелки вверх-вниз ходят по пунктам.

### 2.2 Лента: стартовый экран (пустая лента)

Блок по центру области ленты (по вертикали чуть выше центра: смещение −40), ширина до 560:

1. `start_subtitle` — 18, межстрочный 1,4, `--c-text`, по центру.
2. Пять примеров `examples` — основные пилюли, по центру, с переносом, зазор 8, отступ сверху 20. Нажатие сразу отправляет пример (`source: "button"`).

Шапка в этом состоянии без «Новый диалог».

### 2.3 Лента: переписка

Отступ сверху 28, снизу 12. Между сообщениями 18. Ширина — колонка.

**Сообщение пользователя.** Справа, пузырь: отступы 10 14, скругление `--r-bubble`, фон `--c-bubble`, текст 15/1,5, перенос по словам, максимум 80 % колонки. Голосовое — слева в пузыре иконка `Mic` 14 `--c-text-2`, зазор 8. Нажатая кнопка показывается так же, без иконки, с текстом её надписи.

**Ответ ассистента.** Слева, без пузыря и без значка, ширина до `--answer-max`. Части строго по порядку, зазор между частями 10:

1. Текст `text` — 15/1,5, `--c-text`.
2. Карточки `records` (раздел 3), зазор между карточками 10.
3. Блок «Ближайшее» — если пришёл `nearest`: заголовок `label_nearest` (стиль заголовка дня) и карточка.
4. Кнопки `buttons` — пилюли (раздел 4).

Каждая часть есть, только если есть данные.

**Как показывать карточки по kind:**

| kind | Карточки |
|---|---|
| `list` | Группами по дням (раздел 3.3). Первые 20, затем `show_more` с числом следующей порции (по 20) |
| `found` | Плоско, в порядке бэка, с датой в каждой карточке. Первые 5, затем `show_more` (по 10). Если `total` больше длины `records` — под списком `limit_caption` (`shown` = длина `records`) |
| `created`, `confirm`, `conflict`, любой другой | Плоско, все сразу, с датой в каждой карточке |

`show_more` — вторичная пилюля под карточками; после раскрытия всего исчезает. Раскрытие — плавно (`--t-expand`).

**Индикатор «Думаю».** На месте будущего ответа: три точки 6×6, зазор 4, `--c-text-2`, класс `thinking-dot`. Появляется через 0,3 с после отправки. Через 8 с справа от точек текст `thinking_slow` (13, `--c-text-2`, зазор 10). Пока сервер просыпается — вместо `thinking_slow` текст `status_waking`.

**Ошибка запроса.** На месте ответа: значок `CircleAlert` 18 `--c-alarm` + текст ошибки 15 `--c-text`, зазор 8, выравнивание по верху. Ниже, через 10, основная пилюля с иконкой `RotateCw` 15 и текстом `btn_retry`. Текст: `err_network` / `err_timeout` / `err_server`; для `kind: "error"` — `text` из ответа бэка.

**«↓ К новым».** Если человек прокрутил ленту вверх больше чем на 200 px и пришло новое — основная пилюля с `ArrowDown` 16 и `scroll_to_new`, тень `--shadow-float`, по центру колонки, на 12 выше строки ввода. Нажатие — плавная прокрутка вниз, пилюля исчезает.

### 2.4 Низ: строка статуса

Над строкой ввода, в колонке, отступ слева 4, 13/1,4, `--c-text-2`, отступ снизу 6. Пустая — не занимает места. Один текст за раз, приоритет: `status_server_down` > `status_waking` > подсказка голоса > счётчик не здесь (он в поле). `status_server_down` — терракотой со значком `CircleAlert` 14, висит постоянно. Подсказки голоса исчезают через 6 с или при следующем действии.

### 2.5 Низ: строка ввода — обычный режим

Отступ снизу 22 + `env(safe-area-inset-bottom)`, сверху 8. Контейнер на ширину колонки: отступ 8, скругление `--r-input`, рамка 1 px `--c-line`, фон `--c-surface`, элементы в ряд по нижнему краю, зазор 10.

- **Микрофон** слева: 40×40, скругление `--r-icon`, фон `--c-text`, `Mic` 18 `--c-on-dark`, `aria-label` = `btn_mic`.
- **Поле** — textarea без рамки, растёт от 1 до 4 строк, дальше прокрутка внутри; плейсхолдер `input_placeholder` `--c-placeholder`; отступ по вертикали подобрать так, чтобы одна строка стояла по центру кнопок 40.
- **Счётчик** — когда в поле 250+ символов: справа внизу поля `char_counter` (12, `--c-placeholder`); на 300 — `--c-alarm`, и в строке статуса `char_limit`. Больше 300 ввести нельзя.
- **Отправить** справа: 40×40, скругление `--r-icon`, `ArrowUp` 18 (толщина 1,75), `aria-label` = `btn_send`. Поле пустое или только пробелы, или идёт ожидание ответа — фон `--c-line`, иконка `--c-surface`, неактивна. Иначе — фон `--c-text`, иконка `--c-on-dark`.

Фокус поля — рамка контейнера `--c-text-2` (обводку фокуса у самого поля не рисовать).

3. **Распознаваемый текст** — 15 `--c-text`, одна строка, обрезается многоточием с начала (видно конец фразы). Если до записи в поле был текст — он идёт первым, распознанное продолжает его через пробел. Пока ничего не распознано — пусто.

## 3. Карточка записи

### 3.1 Устройство

Отступы 12 14, скругление `--r-card`, рамка 1 px `--c-line`, фон `--c-surface`. Две строки, зазор 4:

- **Верхняя (мета):** 13, `--c-text-2`, иконка типа 14 `--c-accent` + части через « · », зазор после иконки 6. Справа в этой же строке — метка состояния, если есть.
- **Нижняя:** `text` записи — 15/1,4, `--c-text`, переносится полностью (не обрезать).

**Части меты:**

| Ситуация | Мета |
|---|---|
| exact, с временем | `Встреча · чт, 22 окт · 08:00` |
| exact, без времени | `Задача · чт, 22 окт` |
| deadline | `Задача · до вс, 25 окт` (+ ` · 18:00`, если есть время) |
| none | `Задача · без срока` |
| внутри группы дня (list) | дата не пишется: `Встреча · 08:00`; deadline всё равно `до …` |
| type = null | без иконки и слова типа: `чт, 22 окт · 12:00` |

Иконки: встреча `Users`, задача `CircleCheck`, напоминание `Bell`. Слова — `type_meeting`, `type_task`, `type_reminder`.

### 3.2 Формат даты

- Сегодня / завтра / вчера — `сегодня`, `завтра`, `вчера` (строчными внутри меты).
- Иначе — `пн, 19 окт`: день недели двумя буквами, число без нуля, месяц трёхбуквенный: янв фев мар апр мая июн июл авг сен окт ноя дек.
- Год — только если не текущий: `пт, 5 мар 2027`.
- Время — как прислал бэк, `08:00`.
- «Сегодня» определяется по часам устройства (в режиме заглушек — тестовые часы).

### 3.3 Группировка list по дням

- Записи идут в порядке бэка; подряд идущие с одной датой — одна группа.
- Заголовок группы: 12/600, капс, разрядка 0,04em, `--c-text-2`; отступ сверху +4 к обычному зазору. Текст: `Сегодня, ср 21 окт` / `Завтра, чт 22 окт` / `Вчера, вт 20 окт` / иначе `Пт, 23 окт`; год — если не текущий. (Капс делает CSS, в разметке — обычный регистр.)
- Записи без даты (`none`) — одна группа в самом конце с заголовком `group_no_date`.

### 3.4 Состояния

Одна карточка может иметь несколько; приоритет оформления сверху вниз.

| Состояние | Когда | Вид |
|---|---|---|
| Черновик | `marks` содержит `draft` | рамка 1 px пунктиром `--c-draft-line`, фон прозрачный; справа в мете `label_draft` 12 `--c-text-2` |
| Совпадает | `marks` содержит `conflict` | рамка `--c-alarm-line`, фон `--c-alarm-bg`; справа в мете `CircleAlert` 13 + `label_conflict` 12 `--c-alarm` |
| Новая | `marks` содержит `new` и ответ пришёл сейчас (не восстановлен) | класс `is-new` на 2 с: рамка `--c-accent`, фон `--c-new-bg`, гаснут к обычным |
| Выполнена | `status: "done"` | текст и иконка `--c-text-2`, текст зачёркнут цветом `--c-placeholder` |
| Прошедшая | см. ниже | текст и иконка `--c-text-2` |
| Выделенное поле | `highlight` = date / time / text | эта часть на подложке `--c-mark`, отступ 0 3, скругление 3, цвет `--c-text` |

**Прошедшая** (считает фронт): exact с временем — дата+время раньше «сейчас»; exact без времени и deadline — дата раньше сегодняшней; none — никогда. Черновик прошедшим не бывает.

Клик по карточке ничего не делает (в MVP).

## 5. Телефон (≤ 760 px)

- `--gutter` 16, шапка 56; «Новый диалог» — только иконка.
- Колонка — на всю ширину минус 2×16; ответ и карточки — на всю колонку; пузырь — до 85 %.
- Поля ввода 16 px (иначе iOS приближает страницу).
- Строка ввода всегда над клавиатурой: `100dvh`, без `position: fixed` поверх клавиатуры.
- После отправки клавиатура прячется (поле теряет фокус). На компьютере — фокус остаётся в поле.
- Наведения нет.

## 6. Тёмная тема

Включается сама по настройке системы, переключателя нет. Все цвета — токены, у каждого есть тёмное значение в `tokens.css`. Отдельно ничего рисовать не нужно. Главные кнопки в тёмной теме светлые с тёмной иконкой — это уже заложено в `--c-text` / `--c-on-dark`.
