# 06. План сборки

11 шагов. На каждом: что сделать, промпт для ИИ-агента (копировать как есть) и проверка «готово, если…». Следующий шаг — только когда проверка прошла. После каждого шага — коммит.

Если агент предлагает что-то, чего нет в документах (новый текст, цвет, поведение), — не принимать, а спросить Матвея. Технические вопросы (библиотеки, структура кода, сборка, деплой, отладка) Арина решает сама.

---

## Шаг 0. Подготовка (руками, 10 минут)

1. `npm create vite@latest stevens-front -- --template react-ts`, затем `cd stevens-front && npm i`.
2. Скопировать в корень репозитория из пакета: `AGENTS.md`, `CLAUDE.md`, папку `docs/`.
3. Скопировать содержимое `starter/src/` в `src/` (с заменой).
4. Создать `.env.development` с содержимым из комментария внизу `src/config/features.ts`.
5. Коммит «старт».

## Шаг 2. API, заглушки, часы, даты

**Промпт:**
> Прочитай AGENTS.md, docs/05-api.md, docs/03-behavior.md (разделы 2–5), src/api/types.ts, src/api/mocks.json (особенно meta). Сделай:
> 1) src/lib/clock.ts — функция now(): в режиме заглушек всегда ровно 2026-10-21T10:00:00+03:00 (стоит на месте, чтобы примеры выглядели одинаково); иначе реальное время. Таймеры (индикатор, таймауты) от now() не зависят. Везде в коде «сейчас» — только через now().
> 2) src/lib/dates.ts — форматирование по docs/02-screens.md разделы 3.1–3.3: дата в мете карточки, заголовок группы дня, признак «прошедшая». С юнит-тестами (vitest) на примеры из этих разделов, включая смену года.
> 3) src/api/ — zod-схемы по types.ts; функции health(), chat(), а также login(), register(), logout(), me(), resetSandbox(); заголовок режима по docs/03-behavior.md раздел 1; таймауты; превращение сбоев в типизированные ошибки (network / timeout / server / unauthorized) по разделу 4; проверка ответа схемой по разделу 3.
> 4) Мок-режим: ответы из mocks.json по правилам meta, задержка 600–900 мс, особые фразы, мок входа по meta.auth_mock. Переключение по apiMode.
> Интерфейс пока не трогай.

**Готово, если:** тесты дат проходят; из консоли браузера вызов `chat` с «Что у меня сегодня?» возвращает ответ с двумя записями; `#timeout` даёт ошибку timeout через 25 с; `#500` — server; незнакомая фраза — `not_understood`.

## Шаг 4. Ответы: карточки, кнопки, списки

**Промпт:**
> Прочитай AGENTS.md, docs/02-screens.md разделы 2.3, 3, 4. Сделай отрисовку ответа ассистента целиком: порядок частей, карточки со всеми состояниями (черновик, совпадает, новая, выполнена, прошедшая, выделенное поле), группировку list по дням с группой «Без срока», «Показать ещё» для list (по 20) и found (5, потом по 10), подпись лимита, блок «Ближайшее», кнопки-пилюли с видами основная / вторичная / выбранная / погасшая. Нажатие кнопки отправляет её по docs/03-behavior.md раздел 2 и 3. Незнакомый kind рисуется по общим полям.

**Готово, если** (фразы из заглушек):
- «Что у меня сегодня?» — заголовок дня «Сегодня, ср 21 окт», карточка 08:00 приглушена, 10:15 обычная;
- «Что у меня в ноябре?» — группы по дням, 20 записей и «Показать ещё (11)»;
- «Найди задачу про презентацию» — 5 карточек, «Показать ещё (10)», подпись «Показаны 50 самых подходящих из 103»;
- «Когда у меня была встреча с Иваном?» — даты на подложке-маркере;
- «Что у меня 6 ноября?» — текст + «Ближайшее» с карточкой;
- «Поставь встречу с Еленой в субботу в 20:45» — черновик пунктиром, совпадающая терракотой, 4 кнопки; нажатие «Оставить обе» — кнопка становится тёмной, остальные гаснут, в ленте сообщение «Оставить обе», ответ с подсвеченной новой карточкой;
- `#list_mixed` — дедлайн «до вс, 25 окт», запись без иконки типа, группа «Без срока» последней;
- `#unknown_kind` — текст, карточка и кнопка без ошибок.

## Шаг 11. Финальная проверка

Пройти руками по живой ссылке (full), в Chrome на компьютере и на телефоне:

1. Открыть в приватном окне → экран входа понятен без объяснений.
2. Песочница → нажать каждый из пяти примеров.
3. Голосом: «Напомни завтра в 10 позвонить Ивану» → карточка с подсветкой.
4. «Поставь встречу с Иваном завтра» → «Во сколько?» → кнопка → встреча создана.
5. Встреча на занятое время → совпадение → «Оставить обе».
6. Выключить интернет → отправить → ошибка → включить → «Повторить».
7. F5 → лента на месте, кнопки погашены.
8. Регистрация → пустой аккаунт → создать запись → выйти → войти снова.
9. Тёмная тема системы → всё читается.
10. Тестовые фразы из контракта (раздел 13) — каждая даёт свой тип ответа.

Найденное — Матвею списком: «что сделал → что ожидал → что увидел».
