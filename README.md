# Голосовой ассистент «Стивенс»

Full-stack прототип умного ассистента для управления личными задачами, напоминаниями и встречами с помощью естественной речи и текста. 

Ассистент понимает свободные формулировки (например, «Напомни завтра в 10 позвонить Ивану»), корректно вычисляет относительные даты, сохраняет данные в базу и находит нужные записи по смыслу.

## 🛠 Стек технологий и архитектура

Проект разделен на два независимых приложения (Frontend и Backend), которые общаются по REST API.

### Backend
* **Язык:** Python 3.10+
* **Фреймворк:** FastAPI, Uvicorn
* **База данных:** PostgreSQL 16 (в Docker), SQLAlchemy 2.0 (асинхронный), asyncpg
* **AI / NLP:** YandexGPT (через OpenAI-совместимый Responses API)
* **Авторизация:** Bearer Token (сессии в БД), хэширование паролей через `passlib[bcrypt]`
* **Парсинг дат:** `dateparser` (превращает «завтра» в точную дату на основе времени клиента)

### Frontend
* **Стек:** React 19, TypeScript (strict), Vite
* **Стилизация:** CSS-переменные (дизайн-токены), IBM Plex
* **Валидация API:** Zod
* **Голос:** Web Speech API (распознавание речи в браузере)

### Как это работает:
1. Фронтенд отправляет текст (или распознанную речь) на эндпоинт `POST /api/chat`, передавая токен авторизации и текущее время клиента (`client_time`).
2. Бэкенд отправляет текст в YandexGPT для извлечения намерения (создать задачу, найти, показать список) и сущностей (дата, время).
3. Python-код нормализует ответ нейросети и с помощью `dateparser` превращает относительные даты («завтра») в точные (`2026-10-22`).
4. Логика сохраняет запись в PostgreSQL или ищет существующие (с привязкой к текущему пользователю).
5. Ответ формируется по шаблонам (согласно контракту) и отдается фронтенду в формате JSON.

## 📦 Запуск проекта локально

Для запуска вам понадобятся:
1. **Docker Desktop** (для базы данных).
2. **Python 3.10+** (для бэкенда).
3. **Node.js 20+** и **npm** (для фронтенда).
4. Ключи доступа к **Yandex Cloud** (AI Studio).

Проект состоит из двух частей (Backend и Frontend), поэтому запускать их нужно в **двух разных терминалах**.

### Шаг 1: Настройка окружения (Backend)

1. Откройте терминал в корне проекта (`voice_assistant`).
2. Создайте и активируйте виртуальное окружение:
   python -m venv venv
   
   # Для Windows:
   venv\Scripts\activate
   # Для Mac/Linux:
   # source venv/bin/activate
3. Установите зависимости:
pip install -r requirements.txt

В корне проекта (рядом с docker-compose.yml) создайте файл .env и заполните его:

DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5433/taskapp
YANDEX_API_KEY=ваш_api_ключ_здесь
YANDEX_FOLDER_ID=ваш_folder_id_здесь

### Шаг 2: Запуск базы данных (Docker)
Убедитесь, что Docker Desktop запущен (иконка кита в трее должна быть активна).

В корне проекта выполните команду:

docker compose up -d
Проверьте, что контейнер запустился и здоров:

docker compose ps
В колонке STATUS должно быть написано Up (healthy).

### Шаг 3: Запуск Бэкенда (Терминал №1)
В том же терминале (где активирован venv и вы находитесь в корне проекта) выполните:

uvicorn app.main:app --reload
При первом запуске вы увидите в логах, как SQLAlchemy создает таблицы (CREATE TABLE tasks...).
Если всё прошло успешно, в конце появится строка Application startup complete.

Проверка: Откройте в браузере http://127.0.0.1:8000/docs. Вы должны увидеть Swagger-документацию с эндпоинтами /api/auth/register, /api/chat и т.д.

### Шаг 4: Настройка и запуск Фронтенда (Терминал №2)
Не закрывая первый терминал с бэкендом, откройте новое окно терминала.

Перейдите в папку с фронтендом:

cd frontend
Установите зависимости (это займет пару минут):

npm install
Создайте файл .env.development.local в папке frontend и добавьте туда:

env
VITE_API_MODE=real
VITE_API_URL=http://localhost:8000
VITE_FEATURE_AUTH=true
Запустите сервер разработки:

npm run dev
В консоли появится адрес: http://localhost:5173/.

### Шаг 5: Проверка работы приложения

Откройте в браузере http://localhost:5173.

Вы увидите экран входа. Нажмите «Регистрация».

Введите имя, email (например, test@test.ru) и пароль (от 6 символов). Нажмите «Создать аккаунт».

Если регистрация прошла успешно, вы попадете в чат.

Напишите в поле ввода: «Напомни завтра в 10 утра позвонить Ивану» и нажмите Enter.

Ассистент Стивенс должен ответить и показать карточку созданной задачи.

Попробуйте нажать на иконку микрофона и произнести эту же фразу (работает в Chrome/Edge при наличии HTTPS или на localhost).

### Как остановить проект

В терминале с фронтендом нажмите Ctrl + C.

В терминале с бэкендом нажмите Ctrl + C.

Чтобы остановить базу данных, выполните в корне проекта:

docker compose down
(Если хотите полностью удалить все данные из базы, используйте docker compose down -v).
