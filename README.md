# Голосовой ассистент «Стивенс»

Прототип умного ассистента для управления личными задачами, напоминаниями и встречами с помощью естественной речи и текста. 

Ассистент способен понимать свободные формулировки (например, «Напомни завтра в 10 позвонить Ивану»), корректно вычислять относительные даты, сохранять данные в базу и находить нужные записи по смыслу.

## 🛠 Стек технологий и архитектура

Проект разделен на слои, чтобы отделить работу с голосом/текстом от бизнес-логики и хранения данных.

* **Backend:** Python 3.13, FastAPI, Uvicorn.
* **База данных:** PostgreSQL 16 (запускается в Docker), SQLAlchemy 2.0 (асинхронный движок `asyncpg`).
* **AI / NLP (Понимание языка):** YandexGPT (через OpenAI-совместимый Responses API).
* **Парсинг дат:** `dateparser` (для вычисления «завтра», «в пятницу» и т.д. относительно времени клиента).

### Как это работает (Pipeline):
1. Фронтенд (или Swagger) отправляет текст и текущее время клиента (`client_time`) на эндпоинт `POST /api/chat`.
2. Модуль `brain.py` отправляет текст в YandexGPT, который извлекает намерение (создать задачу, найти, показать список) и сущности (текст задачи, относительную дату, время).
3. Python-код нормализует ответ нейросети (чистит текст, убирает падежи) и с помощью `dateparser` превращает относительные даты в точные (формат `YYYY-MM-DD`).
4. Логика в `chat.py` сохраняет запись в PostgreSQL или ищет существующие.
5. Ответ формируется по заранее заданным шаблонам (согласно контракту) и отдается в формате JSON.
