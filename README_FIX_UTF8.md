# YandexGPT: диагностика и защита ввода

1. `docker compose up -d --build backend`
2. `docker compose exec backend python -m tools.diagnose_llm`
3. `docker compose exec backend python -m pytest tests/test_llm_quality.py -q` (если pytest установлен в образе)

Почему прежний тест неверен: PowerShell на Windows при `@'...'@ | docker compose exec -T backend python -` может передать вместо кириллицы ASCII `?`. Модель получает `????`, но уверенно генерирует примеры из системного промпта. Встроенный модуль диагностики использует Unicode escape-последовательности в коде, поэтому запускается без передачи русского текста через stdin.

Изменения: дополнительные примеры календарных команд в `ru_prompt`; защита от повреждённого текста и очевидно выдуманных названий записи; регрессионные тесты. Это защитные меры, а не гарантия полной точности. Не запускайте тесты на реальных календарных данных: диагностический модуль только разбирает строки.
