# Stevens — фронт строго по контракту v1.4 с допами

Вторая версия фронта рядом с `frontend/`. Бэк общий и не меняется.
Источник правды — [контракт v1.4 с допами](docs/reference/contract_v1.4_s_dopami.pdf).

## Чем отличается от `frontend/`

| | `frontend/` (порт 8080) | `frontend-contract/` (порт 8081) |
|---|---|---|
| Под что написан | под текущий бэк | под контракт v1.4 с допами |
| Кнопки-действия («Отменить», «Да, верно», «Оставить обе»…) | не отправляет | отправляет `action`, как в контракте |
| Проверка сервера | `GET /` | `GET /api/health` |
| Заголовок `X-Stevens-Features` | нет | `d2,d3,d10` при включённых допах |
| Календарь, правка, удаление | нет | `GET/PATCH/DELETE /api/records…` |
| Ответ не по контракту | показывает как получится | ошибка «Ответ сервера не совпадает с контрактом» |
| Песочница и деморежим | есть | нет |
| Вход и регистрация | по email | по email (как в бэке, не по разделу 14) |

Чего бэк не умеет, то фронт не подделывает: показывает ошибку из контракта и
мелкую техническую подпись, какой запрос не прошёл, например
`GET /api/records → 404`. По этим подписям видно, что осталось сделать на бэке.

## Допы (раздел 15)

Все включены. Каждый можно выключить в меню профиля (кружок справа в шапке →
«Допы»), выбор хранится в браузере. При сборке значение по умолчанию задаётся
`VITE_FEATURE_D2=false` и т. п.

- **Д2 Удаление.** Фраза «Удали…» уходит с `d2` в заголовке; карточка с меткой
  `deleted` бледная, с подписью «Удалено». В календаре — «Удалить» и «Вернуть».
- **Д3 Отметка выполненной.** Ответ `completed`; в календаре — «Выполнено» /
  «Не выполнено» у задач и напоминаний.
- **Д10 Отменить и исправить.** «Отменить» присылает бэк; «Исправить» рядом
  добавляет фронт и правит запись через `PATCH /api/records/{id}`.
- **Д6 Календарь.** Неделя записей справа на широком экране, на телефоне — по
  кнопке в шапке. «В то же время» у встреч фронт ставит сам.
- **Д12 Озвучка.** Читает `speech` (или `text`) голосом браузера. Кнопка звука в шапке.
- **Д13 Автослушание.** Если человек говорил голосом, а ассистент задал вопрос
  (`awaiting_reply: true`), микрофон включается сам после озвучки.
- **Д14 Персонаж.** Стивенс в шапке и на стартовом экране: слушает, думает, говорит.

## Запуск

Вместе со всем проектом: `docker compose up --build` в корне репозитория,
откройте http://localhost:8081 (старая версия — на 8080).

Отдельно (Node.js 22+, бэк на `localhost:8000`):
```
npm install --global pnpm@11.25.0
pnpm install
pnpm dev        # http://127.0.0.1:5174
pnpm test
```
