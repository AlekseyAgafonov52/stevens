# Stevens — прототип фронта по контракту v1.4 с допами

Собран заново по пакету «вариант 2 с допами»: `AGENTS.md`, `docs/01–09`, эталонные картинки в
`docs/reference/screens/`. Бэк — в корне репозитория, тоже по контракту v1.4 (вход по логину, песочница,
`/api/records`).

## Запуск

- Всё сразу: в корне `docker compose up --build`, открыть http://localhost:8081.
- Для разработки: бэк на `localhost:8000`, затем
  ```
  pnpm install
  pnpm dev          # http://127.0.0.1:5174, /api проксируется на :8000
  ```
- Проверки: `pnpm lint && pnpm typecheck && pnpm test`.

## Наборы сборки

| Файл | Что |
|---|---|
| `.env.production` | сборка для Docker (порт 8081): настоящий бэк, вход и все допы включены |
| `.env.development` | `pnpm dev`: то же |
| `.env.minimal` | первый вариант без допов и без входа: `pnpm build --mode minimal` |

Флаги — `src/config/features.ts`. Выключенный доп не рисуется и не грузится.

## Устройство

- `src/api/` — все запросы, проверка ответов (zod), заголовок `X-Stevens-Features`.
- `src/state/` — одно хранилище (лента, режим, ожидание, запись), сессия, отправка, хранение ленты, события
  `onAssistantResponse` / `onUiActivity` для допов.
- `src/components/` — первый вариант: вход, шапка, лента, карточки, строка ввода, окна.
- `src/extensions/` — точки расширения из `docs/09-extensions.md`; только здесь проверяются флаги допов.
- `src/extras/` — допы: `calendar` (Д6), `edit` (Д10 и форма правки для календаря), `deleted-card` (Д2/Д10),
  `mascot` (Д14), `speech` (Д12), `autolisten` (Д13).
- `src/voice/` — голос (Web Speech API), `src/storage/` — localStorage, `src/lib/clock.ts` — «сейчас».

Режим заглушек (`apiMode: 'mock'`, `mocks.json`) не перенесён: прототип работает с настоящим бэком.

## Расхождения с эталонными картинками

- В ответе на «Что у меня сегодня?» бэк пишет «На сегодня — 2 дела:», а на картинке «Сегодня — 2 дела:».
  По контракту (раздел 9) `{period}` для сегодня — «на сегодня», поэтому оставлено по контракту.
- Поля даты и времени в форме правки — системные `<input type="date|time">`: их вид зависит от браузера и языка
  системы (на картинке — «24.10.2026» и «14:15»).
