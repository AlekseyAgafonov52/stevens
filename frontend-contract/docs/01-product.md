# 01. Продукт

## Что это

**Stevens** — голосовой и текстовый ассистент для задач, напоминаний и встреч. Отборочное задание хакатона Gorkycode. Человек говорит или пишет обычной фразой («Напомни завтра в 10 позвонить Ивану»), ассистент записывает, показывает планы за период, находит старые записи, переспрашивает, если чего-то не хватает.

Жюри само открывает ссылку и проверяет без инструкций. Поэтому главное: **понятно за 10 секунд, работает без микрофона, ничего не ломается**.

**Критерии оценки (ТЗ):** работоспособность, качество понимания запроса, качество кода, UX — насколько естественно идёт разговор, в том числе когда данных мало.

**Аудитория:** занятые школьники, студенты, деловые люди. **Характер интерфейса:** незаметный, спокойный, надёжный, отточенный, структурный, немного изящества.

## Как устроено (тонкий клиент)

- **LLM** только разбирает фразу в JSON.
- **Бэк** считает даты, проверяет, пишет в базу, собирает текст ответа по шаблонам, решает, какие кнопки показать.
- **Фронт** (это мы): принимает текст или голос, распознаёт речь в браузере, отправляет, рисует ответ по его типу (`kind`). Сам фронт считает только «прошла запись или нет» и показывает ошибки сети.

Фронт **не сочиняет** фраз ассистента и не решает, какие кнопки нужны: всё приходит от бэка. Чего бэк не прислал — того нет.

## Словарь

| Слово | Значение |
|---|---|
| Запись | Сохранённая задача, напоминание или встреча. В интерфейсе пользователю — «планы» |
| Задача | Дело; дата и время необязательны. «До пятницы» — срок (deadline) |
| Напоминание | Дело с моментом, когда напомнить: дата и время есть |
| Встреча | Событие в конкретное время |
| Песочница | Режим без регистрации: своя копия демо-данных организаторов (1000 записей) на это устройство |
| Аккаунт | Режим после входа: свои записи, сначала пусто |
| Уточнение | Вопрос ассистента, когда данных не хватает («Во сколько встреча?») |
| Совпадение | Новая встреча на то же время начала, что и существующая |
| Лента | История сообщений текущего диалога |

Ответить на уточнение необязательно: новый запрос просто начинает новое действие.

## Допы (второй вариант)

Первый вариант — без допов. Второй — тот же код плюс допы, каждый под своим флагом (`src/config/features.ts`): удаление (Д2), отметка выполненной (Д3), встроенный календарь (Д6), «Исправить» и «Отменить» у созданной записи (Д10), озвучка ответов (Д12), автослушание после уточнения (Д13), персонаж Stevens (Д14). Описание — `07-extras.md`, `08-mascot.md`; как встраивать — `09-extensions.md`. Все флаги допов выключены — в точности первый вариант.

Не делаем: изменение записи голосом (Д1), контекст диалога (Д4), повторяющиеся (Д5), пуш-уведомления (Д7), несколько действий в одной фразе (Д9), свободные слоты (Д11).

## Принципы, которые нельзя нарушать

1. Каждый ответ показывает, **что ассистент понял и сделал** (текст + карточка).
2. На каждый сбой — **понятное сообщение и путь дальше** («Повторить», текстом вместо голоса).
3. **Текст работает всегда**, голос — дополнение.
4. **Ни одного придуманного текста или цвета**: тексты — `texts.ts`, цвета и размеры — `tokens.css`.
5. **Рендер по общим полям ответа**: незнакомый `kind` не ломает интерфейс.
