# 08. Персонаж Stevens (доп Д14)

Флаг `d14_mascot`. Выключен — персонажа нет нигде, всё как в первом варианте (`reference/screens/mvp/`). Включён — как на `reference/screens/full/` и `full/mascot-*.png`.

## 1. Готовые файлы

| Файл | Что |
|---|---|
| `src/assets/mascot/stevens-rest.svg` | покой |
| `stevens-think.svg` | думает |
| `stevens-listen.svg` | слушает (держит слуховую трубку) |
| `stevens-puzzled.svg` | не понял |
| `stevens-done.svg` | готово |
| `stevens-write-read.svg` | пишет: фаза «читает поле» |
| `stevens-write-1.svg`, `-2`, `-3` | пишет: три кадра письма |
| `src/styles/mascot.css` | место на экране, смена состояний, все анимации, режим без анимаций |

**Как вставлять.** Только inline (содержимое SVG в разметку, например через импорт `?raw` в Vite). Через `<img>` нельзя: цвета внутри — CSS-переменные из `tokens.css` (`--c-text`, `--c-surface`, `--c-accent`, `--c-text-2`, `--c-mascot-*`), и тёмная тема включается сама только при inline-вставке. Рисунки не перерисовывать и не упрощать.

Все SVG — `viewBox="0 0 120 140"`; низ фигуры — на `y = 128`. `aria-hidden="true"`: персонаж декоративный, состояние для диктора не дублируется.

## 2. Где живёт

**В приложении — сидит на строке ввода, сверху справа** (как на `full/mascot-in-chat.png`):
- контейнер строки ввода — `position: relative`, персонаж — `.stevens-perch` из `mascot.css`;
- компьютер: ширина 96, отступ справа 22; телефон: ширина 72, отступ справа 18;
- низ фигуры стоит ровно на верхней рамке поля (формула — в `mascot.css`);
- нажатия ловит только сама фигура (клик — поклон или кивок), пустые поля рисунка их пропускают;
- ленте добавляется запас снизу (`.feed--with-mascot`: 122 на компьютере, 94 на телефоне), чтобы последнее сообщение не уходило под персонажа;
- виден и на стартовом экране, и в переписке; на экране входа в этом месте его нет.

**На экране входа — справа от слова «Stevens»** (как на `full/login.png`):
- ряд «слово + персонаж»: `display: flex; align-items: baseline; gap: 8px`; низ рисунка совпадает с низом букв;
- рисунок «покой», но обрезанный по фигуре: `viewBox="34 12 52 117.4"`, высота 66 (телефон 58) — класс `.stevens-title`;
- не анимируется.

## 3. Состояния и когда какое

Приоритет сверху вниз — если подходят несколько, показывается верхнее.

| # | Состояние | Когда | Файл |
|---|---|---|---|
| 1 | Слушает | идёт запись голоса (от старта записи до отправки распознанного) | `listen` |
| 2 | Думает | сообщение отправлено и ждём ответ (включая пробуждение сервера и «Повторить») | `think` |
| 3 | Пишет | человек печатает: в поле есть текст и последнее нажатие клавиши было меньше 1,5 с назад | `write-*` |
| 4 | Конфликт | после ответа с `kind` `conflict`, до следующего запроса | `concern` |
| 5 | Поклон / кивок | поклон — сразу после входа (аккаунт или песочница) и при «Новом диалоге»; по клику — поклон, следующий клик — кивок, не чаще раза в 2 с | `bow-1`, `bow-2` |
| 6 | Не понял | 3 с после ответа с `kind` `not_understood` или `off_topic` | `puzzled` |
| 7 | Готово | 3 с после ответа с `kind` `created`, `completed` или `deleted`, а также после сохранения формы «Исправить» в ленте | `done` |
| 8 | Покой | всё остальное: ошибки, уточнения, списки, поиск, пустое поле | `rest` |

- «Не понял» и «готово» гаснут в покой через 3 с, или раньше — если началось состояние выше по приоритету (человек начал печатать, записывать или отправил новое).
- Восстановленная после перезагрузки лента состояний не запускает: персонаж в покое.
- Действия в календаре (отметка, правка, удаление) персонажа не меняют.

## 4. Движение

| Состояние | Что двигается | Как |
|---|---|---|
| Смена любого состояния | весь персонаж | два слоя, плавная смена прозрачности 300 мс (`.stevens-layer`) |
| Покой | ничего | — |
| Думает | точки мысли | мигают по очереди, цикл 1,2 с (`.stv-dot`). Если ответа нет 1,5 с — по кругу по 2 с: точки → постукивает карандашом по блокноту (`think-tap`, `.stv-tap`) → сверяется с записями (`think-read`) |
| Слушает | трубка с кистью | покачивается у уха, 0,6 с туда-обратно (`.stv-horn`); размах от громкости голоса: ±1° в тишине, до ±7° (`--stv-amp`) |
| Конфликт | очки | приподнимаются за 0,7 с и остаются чуть выше (`.stv-glasses`) |
| Поклон | весь персонаж | покой → `bow-1` → `bow-2` (держит 0,6 с) → `bow-1` → покой, ≈1,2 с; кивок — только `bow-1` на 0,45 с |
| Ночь (23:00–6:00 по часам устройства) | колпак | отдельный слой поверх любого кадра (`stevens-nightcap.svg`, `.stevens-cap`), в поклоне опускается вместе с головой; в покое вместо `rest` — `rest-night` (глаза полуприкрыты) |
| Не понял | знак вопроса | появляется за 200 мс (`.stv-question`) |
| Готово | искорки | один раз вспыхивают за 600 мс (`.stv-sparkle`) |
| Пишет | кадры | цикл: «читает поле» 1,2 с → письмо 1,6 с (кадры `1 → 2 → 3 → 2` по 200 мс, дважды) → снова «читает». Между «читает» и «пишет» — смена прозрачности 150 мс, между кадрами письма — мгновенно |

**Без анимаций по настройке системы** (`prefers-reduced-motion: reduce`): ничего не мигает и не качается, смена состояний мгновенная, «пишет» показывает неподвижный кадр `write-1`, «думает» — только точки, поклона и кивка нет, колпак на месте. Всё это уже в `mascot.css`, кроме цикла «пишет» — его делает JS, и он должен проверять эту настройку.

## 5. Что меняется в первом варианте при включённом флаге

| Место | Флаг выключен (первый вариант) | Флаг включён |
|---|---|---|
| Индикатор ожидания в ленте | три точки, через 8 с — точки + `thinking_slow` | **точек нет** — ждёт персонаж; через 8 с на месте ответа только текст `thinking_slow` (13, `--c-text-2`); при пробуждении — `status_waking` |
| Строка записи | как есть | как есть (столбики громкости остаются) + персонаж «слушает» |
| Экран входа | только «Stevens» | «Stevens» + персонаж справа |
| Нижний запас ленты | 12 | 84 / 74 |

Больше персонаж ничего не меняет.
